# v1.1.0 Ring-3 Memory Foundation Evidence

> **Status:** Final release evidence.
> **Date:** 2026-08-01  
> **Environment:** WSL2 Linux x86_64; pinned Rust nightly; QEMU UEFI; Limine 12.4.2

## Scope

This evidence record covers the v1.1.0 Ring-3 memory foundation. It does not
claim completion of the Draft hardware IRQ architecture or production-service
allocator migration. Those boundaries are recorded in ADR 0039 and the v1.1
roadmap.



## v1.1.0 Proofs

| Proof | Command/profile | What it establishes |
| --- | --- | --- |
| Factory authorization and rollback | `cargo xtask run --headless --test factory-correctness` | Factory type filtering, page-rounded quota, narrow rights, and rollback without published state |
| Real memory lifecycle | `cargo xtask run --headless --test memory-lifecycle` | Ring-3 factory creation, mapping, volatile access, handle deletion, remapping, and clean exit |
| Fallible Ring-3 heap | `cargo xtask run --headless --test ring3-heap` | `Box`/`Vec` allocation, alignment, fragmentation, quota exhaustion through `try_reserve_exact`, and post-OOM recovery |
| Host ownership tests | `cargo test --workspace --locked` | ABI status encoding, ResourceDomain accounting, capability lineage, reference accounting, allocator metadata, and workspace integration |
| Complete regression matrix | `cargo xtask test` | Locked target builds, host tests, strict profile Clippy, all deterministic UEFI guest proofs, and normal ISO restoration |
