## 3. Technical Debt & Known Gaps

1. **Ring-3 Heap Allocator:** Global allocator returns `null_mut()`. Scheduled for Initiative `v1.1.0`.
2. **Physical AP Bring-up:** SMP execution runs on single-core BSP; IPI delivery is simulated. Scheduled for Initiative `v1.2.0`.
3. **GaxFS Durable Core:** Persistent root reconstruction and BLAKE3 hash integrity scheduled for Initiative `v1.3.0`.
4. **Network Transmit & TLS Handshake:** Transport handoff and TLS 1.3 handshake negotiation scheduled for Initiative `v1.4.0`.
5. **IOMMU DMA Isolation:** Bus-mastering drivers operate as trusted drivers pending VT-d/AMD-Vi in Initiative `v1.5.0`.
