# Gaxera v1.1.0 Release Candidate

> **Status:** Closeout candidate; bind this record to the final release commit before tagging.  
> **Scope:** Ring-3 Memory Foundation  
> **Date:** 2026-08-01

## Release Boundary

v1.1.0 extends the v1.0.0 capability microkernel baseline with the memory
authority and fallible Ring-3 heap mechanism needed by later runtime and driver
work. It does not claim that hardware IRQ delivery or production service
bootstrap is complete.

## Delivered

- ResourceDomain physical-byte quota accounting with checked charge, rollback,
  and release operations.
- Factory type authorization and narrow `MemoryObject` capability rights.
- Page-rounded, zero-filled, non-executable anonymous memory creation.
- Fallible physical-frame allocation with complete rollback on partial failure.
- MemoryObject capability, mapping, and transient reference classes.
- Capability-node mapping lineage and selective revocation cleanup.
- Explicit `MapMemory`/`UnmapMemory` lifecycle integration, TLB invalidation,
  frame reclamation, and quota refund.
- `libgaxera::UserspaceAllocator` with explicit Factory/AddressSpace
  initialization, fixed 64 KiB chunk growth, out-of-band free-list metadata,
  alignment handling, deferred coalescing, and null-on-exhaustion behavior.
- Genuine Ring-3 lifecycle and heap test services.


## Deferred Work

- Hardware IRQ delivery remains in Draft at
  `docs/architecture/irq_delivery.md`.
- Production service migration remains deferred until a process-bootstrap ADR
  defines Factory, AddressSpace, CapabilitySpace, and failure-reporting
  authority for every loaded service.
- Size-class slab bins, direct large allocations, guard-page insertion, page
  decommitment, allocator ASLR, and SMP runtime lock enforcement remain future
  work. These are not silently represented as v1.1.0 features.
